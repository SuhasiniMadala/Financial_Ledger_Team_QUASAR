
# AGENTS.md

## Project
Financial Ledger – Team QUASAR

## Overview
This project aims to develop a Financial Ledger system for maintaining, tracking, and managing financial transactions.

Refer to the project SRS in the repository for the complete functional and non-functional requirements.

## General Instructions

1. Always refer to the SRS before implementing any feature.
2. Do not introduce features that are outside the agreed requirements without team approval.
3. Write clean, modular, readable, and maintainable code.
4. Use meaningful variable, function, and class names.
5. Avoid unnecessary code duplication.
6. Handle invalid inputs and errors properly.
7. Add appropriate comments wherever the implementation is not self-explanatory.
8. Test changes before considering a feature complete.

## Git Guidelines

1. Do not commit directly to main for major features.
2. Create separate branches for individual features.
3. Use meaningful commit messages.
4. Review changes before merging.
5. Do not commit passwords, API keys, or sensitive information.

## Documentation

1. Document important technical decisions.
2. Maintain research notes inside the brain/research directory.
3. Update brain/log.md after important team discussions.
4. Keep documentation consistent with the actual implementation.

## Development Guidelines

- Follow the architecture agreed upon by the team.
- Maintain consistency in coding style.
- Ensure changes do not break existing functionality.
- Do not assume requirements that are not mentioned in the SRS.
